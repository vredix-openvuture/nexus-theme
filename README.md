# Nexus

A card-based Obsidian theme. Crisp rather than cozy — clear edges, deliberate
spacing, and a fixed default palette ("Ember & Prussian") built from five
swatches: Aubergine, Rain Boots, Prussian, Madder and Claret. Six further
signature palettes ship alongside it.

Pairs with the [Nexus Suite](https://github.com/vredix-openvuture/nexus-suite)
plugin, which drives the homepage, calendar and card layouts the theme styles.

## Install

Not in the community store — install via
[BRAT](https://github.com/TfTHacker/obsidian42-brat):

1. Install **BRAT** from the community plugin store.
2. `BRAT: Add a beta theme` → `vredix-openvuture/nexus-theme`
3. Select **Nexus** in Settings → Appearance.

BRAT tracks the default branch and updates whenever `version` in
`manifest.json` goes up.

## Manual install

Copy `theme.css` and `manifest.json` into `<vault>/.obsidian/themes/Nexus/`.

## Files

- `theme.css` — the whole theme, hand-written, no build step
- `manifest.json` — name, version, `minAppVersion`; bump `version` to trigger a BRAT update
